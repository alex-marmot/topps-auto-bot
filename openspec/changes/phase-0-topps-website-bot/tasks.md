# Tasks

本轮仅修订规范和任务。已有 UC、登录/下单基础和 209 项历史测试记录保留，但首版默认改为人工登录，移除全局实站验证阻断，补齐多 iframe 支付及软件更新。已确认的加购阻断/超时缺陷对应任务重新待办；不能因旧测试通过而继续勾选。真实账号登录和真实付款属于用户可选试用，不是开发完成条件。

优先顺序为：可试用入口与人工登录 → 实际页面/多iframe处理 → 已知重试与超时修复 → 完整受控回归 → Windows安装与更新交付。允许保留已有有效模块，不重写无关代码；开发不依赖真实账号/卡或成功购买证明。普通用户发布时需有真实可用的固定更新入口；缺构建环境或发布地址需明确列为待验证/待配置，不虚构结果。
