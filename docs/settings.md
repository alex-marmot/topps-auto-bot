# 本地设置与敏感资料

## 配置位置

- Windows：`%LOCALAPPDATA%\ToppsAutoBot\config.json`
- macOS（开发）：`~/Library/Application Support/ToppsAutoBot/config.json`
- 其他平台：`$XDG_DATA_HOME/ToppsAutoBot/config.json` 或 `~/.local/share/ToppsAutoBot/config.json`

程序文件与用户数据分离。不同 Windows 用户各自使用自己的数据目录，程序不会读取其他用户的配置或浏览器会话。

## 数据内容

| 文件/目录 | 内容 |
| --- | --- |
| `config.json` | 配置格式版本、单账号登录资料、商品预设、本次唯一目标、数量、USD 单价/整单上限、收货资料、信用卡资料、驱动/UC 诊断设置；旧定时和窗口字段仅兼容保留 |
| `browser-profile/` | 工具专用 Chrome 登录状态，不使用日常 Chrome 配置 |
| `drivers/` | 已启用驱动 |
| `driver-staging/` | 自动下载或手动复制的私有暂存副本；未验证或未启用的副本不用于购买 |
| `run-state.json` | 未决加购和购买提交记录（schema 2）；兼容旧 schema 1 未决购买记录；不含卡资料、地址、Cookie 或令牌 |
| `logs/` | 脱敏状态与错误分类 |

## 本地明文保存

登录密码和信用卡资料按你的选择保存在本地 `config.json` 中。**本地文件保存不等于加密**，程序也不会声称已加密。请保护当前 Windows 账户和配置文件，不要把配置、浏览器资料或诊断内容提交到 Git、发给他人或上传到无关服务。

界面默认遮蔽登录密码、完整卡号和 CVV；需要修改时使用对应的“显示/编辑”操作。真实账号密码、验证码、卡号、CVV、地址和会话不会进入日志、诊断或 `run-state.json`。验证码不保存、不读取邮箱。

## 首次填写与修改

1. 首次启动没有配置文件时，程序显示设置页并阻止开始购买。
2. 在“商品预设”中填写名称、规格、官网 HTTPS 链接、正整数数量和 USD 单价上限；可保存多个预设。
3. 选择“设为本次唯一目标”。多选、未选、重复商品/规格或未确认目标都不能保存为可执行配置。
4. 填写登录邮箱及官网实际需要的密码；登录账号必须与收货邮箱分开填写。填写收货资料和信用卡资料。金额使用十进制字符串，最多两位小数；整单上限包含税费和运费。
5. 当前基线没有整单提交窗口/倒计时；旧配置中的定时和 window 字段只兼容保留，不会自动运行或限制新任务。普通步骤/加购核对各 30 秒，售罄等待可持续超过 600 秒。
6. 可以直接填写链接、规格、数量和单价后点击“使用当前输入（不保存）”，无需先命名保存预设；搜索候选也只选择一个目标。
7. 保存后，下次启动和下一次任务使用新配置。任务开始后会先复用配置账号的有效会话，否则尝试一次官方表单自动登录；失败/验证码转人工。登录和空车核实后才进入商品流程。
8. 驱动页可显式开启“诊断兼容：关闭 Chrome 沙箱”。默认保持沙箱；改变该选项后必须重新验证 UC 空白启动和实站访问，不能把启动成功当作官网可用。

保存采用“先校验 → 同目录临时文件写入并刷新 → 完整替换”。失败时保留旧配置，清理临时文件，不会显示假保存成功。

## 配送规则

程序只沿用官网唯一明确选中的默认配送服务，确认后记录服务身份、名称和 USD 运费。付款前服务或运费发生变化即停止。程序不提供自动选最低价、最快或指定替代服务的设置，也不在同一任务中重建配送快照。

## 完整下单基线的本地记录

`run-state.json` 使用 schema 2，可同时保存未决加购和未决购买提交：

- 加购在途/结果不明会阻止新任务，直到用户在官方购物车核对并显式记录成功、失败或未形成加购。
- 购买提交中/结果不明会阻止新付款，直到用户在官方订单或支付渠道核对并显式记录结论。
- 旧 schema 1 的购买记录会按旧流程读取并继续阻断，不会因流程改版被当作无记录。
- 解除阻断不会恢复旧任务；新任务仍须空车检查。

## 配置损坏、版本不兼容与修复

- 文件不存在：视为未配置，引导填写，不改写其他文件。
- 文件损坏、字段无效或版本高于当前支持：保留原文件，阻止购买，界面显示原因。
- “备份并重建配置”：仅在用户明确确认后，把原文件改名为带 `.invalid-*.bak` 的备份，再写入新配置。程序不会静默覆盖损坏或更高版本文件。
- 旧版本迁移必须有明确版本规则并通过校验；失败保留原数据。当前配置格式为 v2，v1 配置会受控迁移并保留交易资料，但缺少登录字段时会引导补齐；不提供参考项目配置的兼容导入。

## 升级、清除与卸载

- 升级程序文件不会重置 `%LOCALAPPDATA%\ToppsAutoBot\` 中的配置、浏览器资料或未决付款记录。
- 回退到旧版时，遇到未知配置版本应停止交易，不能用默认模板覆盖。
- 卸载默认保留用户资料；只有用户明确选择清除并再次确认时，才删除本程序的数据目录。程序不会删除用户自行安装的 Chrome 或原始手动下载的驱动文件。
- 手动清除：先关闭程序，确认没有未决加购或付款记录，再删除 `config.json`。`run-state.json` 含未决记录时先按 `docs/payment-recovery.md` 核对，不能通过删除它绕过阻断。

## 分发隔离

`config.example.json` 是本项目编写的空模板，不是可用付款配置。真实配置、备份、浏览器资料、日志和截图必须在 Git 和安装包之外；`.gitignore` 不能替代安装包白名单。
