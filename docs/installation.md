# Windows 安装与驱动维护

## 安装前准备

- Windows 10/11 x64。
- 已安装 Google Chrome（推荐使用官方稳定版）。不需要另外安装 Python、开发工具或命令行组件。
- 首次启动需要网络访问 Chrome for Testing 官方元数据与下载地址；也可以在有网络的机器上下载驱动后手动选择。

安装包为当前用户级安装：不要求管理员权限，程序文件与用户数据分离，通常安装到当前用户的应用目录。安装完成后可打开初始化向导。

## 首次启动

1. 安装后从桌面或开始菜单启动 `Topps Auto Bot`。
2. 程序检测 Chrome 路径、版本和系统架构。找到时会显示路径与版本。
3. 未找到 Chrome 时，程序提供官网下载入口、重新检测或手动选择已有 Chrome 可执行文件；验证成功前保持“未就绪”。
4. 完成本地设置后才能开始完整自动下单流程；未完成初始化或配置时不会启动购买任务。

## 浏览器启动：UC、Chrome 与专用 profile

购买会话使用 Selenium + `undetected-chromedriver`（UC）启动正常可见 Chrome，显式传入已检测的 Chrome 和已验证受管理驱动路径，复用本程序专用持久化 profile，不读取日常浏览器资料。初始参数包含 `--disable-blink-features=AutomationControlled`、`--start-maximized`、`page_load_strategy='normal'` 和 `use_subprocess=True`，UC `version_main` 来自当前检测版本，不写死 146/156。上述方案不保证通过 Cloudflare；普通 Selenium 仅作为明确标识的对照诊断。

默认保留 Chrome 沙箱，并向 UC 显式传入 `no_sandbox=False`。只有针对可复现兼容问题，用户才可在驱动页开启关闭沙箱的诊断选项；改变参数后需要重新验证，不能因 403 自动关闭沙箱。

## 驱动准备：暂存、验证、启用

自动下载和手动选择都遵循同一流程：

1. **私有暂存**：自动模式下载到 `driver-staging/<操作标识>/`，手动模式把选定的 `chromedriver.exe` 复制到同类暂存目录。暂存副本不是已启用驱动。
2. **完整验证**：检查同一份副本的平台、版本与当前 Chrome 主版本，先对同一副本执行 UC 处理，再通过实际 UC 启动、关闭独立空白浏览器。版本号匹配或文件复制成功都不算验证完成；运行阶段不得再隐式下载或修改活动驱动。
3. **原子启用**：验证通过后把副本晋升到 `drivers/`，再保存有效驱动选择。保存失败时旧驱动和旧选择保持；未完成启用的副本不用于购买。

验证过程不读取真实账户或付款配置，不导航购买页面，不使用 `--no-sandbox`。

### 自动下载

- 只使用 Chrome for Testing 官方 HTTPS 元数据和下载地址。
- 按检测到的 Chrome 版本选择兼容驱动，不写死某个 Chrome 主版本，不使用任意镜像兜底。
- 显示版本、下载阶段和进度；没有可靠总大小时只显示已下载字节数或阶段，不伪造百分比。
- 下载、解压和验证都可以取消。

### 下载中取消并手动选择

1. 点击“取消下载，改为手动选择”。
2. 该操作的启用权限被撤销，后台连接终止，未完成文件清理；已启用旧驱动保留。取消后的迟到结果不会覆盖手动选择。
3. 从 Chrome for Testing 官方页面下载与当前 Chrome 主版本匹配的驱动并解压。
4. 在向导中选中解压后的 `chromedriver.exe`。程序只复制并验证副本，不修改原文件，也不会联网补下载。

### 验证或启用失败

- 显示失败阶段和原因，提供重试、手动选择或稍后处理入口，不无限自动重试。
- 新驱动失败不会删除旧驱动；但旧驱动仍需通过当前 Chrome 兼容性检查才能继续使用。
- 完整验证后、启用提交前取消会清理暂存副本，不改变有效选择。
- 若启用已经提交后收到迟到取消，界面显示已完成，不误报取消。

## 每次任务前的检查

开始任务前，程序检查已启用驱动文件存在且主版本与当前 Chrome 兼容。Chrome 更新导致手动驱动失配时，任务不能开始；除非用户主动选择自动模式，否则不会自动下载或替换。任务执行、商品观察、加购、结算或本人验证期间禁止更换浏览器和驱动，修改只影响后续任务。

## 升级与卸载

- 安装更新只更新程序文件；`%LOCALAPPDATA%\ToppsAutoBot\` 中的配置、浏览器资料和 `run-state.json` 保留。未知配置版本会阻止交易并提示处理，不会用模板覆盖。
- 卸载默认保留用户数据。卸载界面明确说明本地信用卡配置和登录状态；只有用户主动选择清除并确认后，才删除本程序数据目录。
- 不会删除用户自行安装的 Chrome，也不会删除原始手动下载的驱动文件。

## 本机验证记录

开发环境（macOS，不是 Windows 验收）：

- CPython 3.14.0 + Tk 8.6 可创建并销毁 Tk 窗口。
- Chrome 156.0.8078.80。
- Chrome for Testing ChromeDriver 156.0.8078.80。
- UC 3.5.5 已加入锁定依赖；macOS 上对 UC 处理后的暂存驱动重新做 ad-hoc 签名后，受控空白启动和本地全流程通过；Windows 和实站组合尚未验收。
- 官方元数据查询、下载、平台/版本检查、空白浏览器启动关闭验证均通过。
- 用户级 Windows 安装、无 Python 环境启动、升级/卸载演练尚未完成；不能把 macOS 或本地模拟结果当作 Windows 安装验收。
