# 使用流程（完整自动下单基线）

本基线复现参考项目的单商品下单顺序：**登录（复用/自动/失败转人工）→ 空购物车 → 商品页 → 选择规格、设置完整数量 → 自动加购一次 → 购物车核对 → 官方结算 → 填写资料 → 一次购买提交 → 核对结果**。普通在售直购商品可用于验证流程；抽签、拍卖或购买机制不明的入口不执行。普通商品成功不代表限量抢购成功率。

## 1. 保存唯一目标和预算

1. 在“设置”中保存一个或多个精确商品预设：名称、规格、官网 HTTPS 链接、完整正整数数量和 USD 单价上限。
2. 从预设中选择一个“本次唯一目标”；其他预设不会进入本次购物车，也不会在目标暂不可购时自动替补。
3. 设置整单 USD 上限（含税费和运费）。
4. 可以直接填写链接、规格、数量和单价后点击“使用当前输入（不保存）”，无需先保存预设；也可以复用已保存预设。保存预设不等于已经加购、已有库存或已进入结算。

当前基线**只支持立即执行，不设整单截止或倒计时**。旧配置中的定时时间/窗口字段可以兼容保留，但不会自动等待、调度或限制新任务；必须由你明确点击“开始完整流程”。

## 2. 基础准备：登录与空车

1. 点击“开始完整流程”；如果尚未打开浏览器，程序会打开正常可见的 Chrome 专用会话。
2. 程序先核实专用会话是否已登录配置账号：一致则复用，不重复提交凭据；未登录时使用本地保存的登录邮箱和官网实际需要的密码，尝试一次官方表单自动登录。
3. 自动登录错误、超时、验证码、人机或额外认证时，程序显示“等待人工登录”，请在同一专用 Chrome 中完成。等待上限 10 分钟，期间不会被固定等待或“已完成”按钮判定成功；程序不重复提交凭据、不读取邮箱、不保存验证码。执行中会话失效则停止，不自动补登录。
4. 官网登录态和配置账号匹配核实后，程序打开官方购物车并确认同一会话的购物车为空。已有任意商品、无法读取或存在未决加购/付款时停止，由你自行处理；程序不会自动清车、删减或接续已有购物车。
5. 环境、配置、精确目标、登录、空车和未决记录检查通过后形成 `RUN_READY`，随后立即进入商品页。界面显示当前步骤、已运行时长和最近结果，不显示整单剩余时间。

## 3. 商品页、规格与数量

1. 程序打开已确认的目标商品链接，核对商品身份。
2. 商品有多个规格时选择预设规格；无法设置或设置后核对不一致即停止。
3. 设置完整数量并回读页面值；数量设置失败、回弹、默认值或页面值不符时停止，不使用默认数量继续。
4. 核对当前 USD 单价和币种；价格未知、非 USD 或超过单价上限时停止。
5. 商品暂不可购/售罄时持续观察同一目标：售罄约每 15 秒、临时不可用或可安全重试的暂拒约每 10 秒，官网要求更久则遵从。累计运行超过 600 秒仍可继续；连续读取异常 3 次才停止。恢复可购后重新核对身份、规格、数量、单价和空车，不自动换目标。

## 4. 自动加购一次

1. 实际加购前再次确认购物车为空。
2. 每次尝试先持久化独立序号的在途记录（任务、目标、数量），保存失败不点击；同一时刻只允许一个在途尝试。
3. 只有可证明上次动作未发出，或官网明确暂时拒绝且确认无副作用、空车、无在途/未决时，才按至少 10 秒间隔新建尝试。点击异常、单次空车观察或提示消失都不构成重试证据。
4. 点击后重新读取购物车；恰好是唯一目标/规格/完整数量且 USD 单价合规才记录成功并立即进入结算。
5. 部分数量、额外条目、规格错误、未知结果或永久拒绝时停止并保留现场；未知会跨停止/重启阻止新加购，直到你核对并显式记录结论。付款仍最多提交一次。

## 5. 结算、配送与付款

1. 从购物车沿官方入口进入结算，填写本地配置中的收货和信用卡资料；填写失败、字段缺失或官网校验错误时停止付款。
2. 只沿用网站唯一明确选中的默认配送服务。地址、商品和完整报价确定后固定服务身份及 USD 运费；服务或费用变化即停止，不自动改选或重建快照。
3. 提交前核对唯一商品/规格/完整数量、当前 USD 单价、小计、税费、运费和整单上限。
4. 全部条件通过时，先保存购买提交记录，再触发**一次**最终购买提交；没有整单截止。记录失败不点击。
5. 提交后等待官方结果或本人验证；本人验证由你在页面完成。程序只核对，不再次提交。

## 6. 步骤超时、停止与结果

- 普通步骤/加购核对各 30 秒，人工登录和付款结果/银行验证各 10 分钟；没有整单截止。售罄等待可超过 600 秒。
- 停止会撤销后续动作，等待在途浏览器操作有限退出；保留浏览器和实际购物车，不自动清车。
- 加购成功不等于订单成功；进入结算不等于已付款；按钮消失或固定等待都不是成功证据。
- 只有能关联本次目标、取得订单标识且付款明确接受才报告成功。明确拒绝报告失败；处理中、无响应、无法关联或相互矛盾报告结果不明。
- 未决加购和未决付款都跨重启阻断。先在官方页面核对并显式记录结论，之后只能开始新任务；新任务仍需空车检查，不恢复旧任务或重发旧动作。

## 7. 当前限制

- 官网访问受限（Cloudflare 403 等）时保持未验证/不支持，不绕过限制，不用内部接口代替。
- 程序目标使用 Selenium + undetected-chromedriver（UC）+ 可见 Chrome 专用 profile；普通 Selenium 仅用于本地受控诊断。macOS 上受控 UC 启动已通过，Windows 和真实官网仍需单独验收。
- 真实页面适配尚未完成现场验证前，`DEFAULT_TOPPs_PROFILE.verified` 为 `False`，界面阻止自动推进；不要把本地受控页面测试当成现网购买成功。
- 不保证库存或抢购成功率；普通在售商品基线结果不能宣传为限量抢购成功。
